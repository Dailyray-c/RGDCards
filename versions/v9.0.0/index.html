红心大战规则

四人各 13 张牌，目标是尽量少收罚分。

罚分牌：每张红心 1 分，黑桃 Q（猪）13 分，一副牌共 26 分。

基本流程：每局开始传牌，然后 13 墩。每墩由上一墩赢家首引，其余三家依次出牌。

必须跟花色：手里有首引花色就一定要跟出，不能垫其他花色。

四条规定：① 首轮不能出红心 ② 首轮不能出黑桃 Q ③ 首引不能出红心 ④ 有牌必须跟花色。若手里只剩下被禁止的牌，则解禁。

首墩首引：第一墩固定由持梅花 2 者首引，且他只能出梅花 2。

收分：比大小只看首引花色，最大者收下这一墩的所有罚分。

满贯（收月亮）：一人独收全部 26 分即为满贯。按当前设置，可让自己 −26 分，或让其余三家各 +26 分。

终局：任一玩家累计达到 100 分即结束，总分最低者获胜。

传牌轮换：向左 → 向右 → 传给对家 → 不传，如此循环。

分值牌：🐷 黑桃 Q（猪）−100；🐑 方块 J（羊）+100；⚡ 梅花 10 是变压器，自身不计分。

红桃扣分：红桃按牌面扣分 —— A −50、K −40、Q −30、J −20、10 −10，2~9 无分（红桃合计 −150）。

变压器：收下 ♣10 的人本局总分翻倍；若他本局刚好 0 分，则改为 +50。

满红：一人收齐全部 13 张红桃，红桃部分整体变为 +200（猪、羊照常另计）。

亮牌（卖牌）：开局前可亮出 猪 / 羊 / 变压器 / 红桃A。亮过的牌在结算时该张分数翻倍——自己吃到亏双倍，被对家吃到对方也双倍。

必须跟花色：手里有首引花色就必须跟出，不能垫其他花色。

首墩首引：第一墩固定由持梅花 2 者首引，且他只能出梅花 2。

与红心大战的区别：拱猪没有"首墩禁红心 / 禁猪"，也没有"首引禁红心"——红桃和猪随时都能出。

终局：任一家累计分 ≤ 设定阈值（默认 −1000）即结束，累计分最高者获胜。

传牌轮换：向左 → 向右 → 传给对家 → 不传，如此循环。
